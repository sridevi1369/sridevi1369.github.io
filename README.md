# Sridevi Portfolio Website

Professional responsive portfolio for Karakam Sridevi.

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Git workflow

```bash
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

Create a feature branch:

```bash
git checkout -b feature/about-section
git add .
git commit -m "Update about section"
git push -u origin feature/about-section
```

Merge it:

```bash
git checkout main
git pull origin main
git merge feature/about-section
git push origin main
```

## GitHub Pages

GitHub repository -> Settings -> Pages -> Deploy from branch -> `main` -> `/ (root)` -> Save.

The portfolio content is based on the provided resume.
